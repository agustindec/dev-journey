60. Objetivo alcanzado

B2 sólido y funcional para trabajar como software developer en un entorno internacional.

Después de esto recién abriríamos la siguiente rama:

B2 sólido → C1 profesional.

Y para estudiar realmente siguiendo este índice, empezaría por el punto 0: diagnóstico, porque no tiene sentido estudiar Present Simple durante semanas si ya lo dominás. El diagnóstico nos permitiría marcar cada punto como dominado, necesita repaso o necesita estudio, y empezar exactamente desde tu primer hueco real.

129. Objetivo alcanzado — C1 profesional

El objetivo no sería simplemente obtener un certificado C1.

Para nuestro roadmap:

C1 profesional = poder estudiar, entrevistar, trabajar y desenvolverte profesionalmente como software engineer prácticamente por completo en inglés.

De esta manera, el roadmap completo queda dividido en dos grandes objetivos:

Etapas 0–12 → B2 sólido

Etapas 13–25 → C1 profesional

Y mantendría el orden de prioridad que definimos: primero alcanzar un B2 sólido, porque ese ya es un nivel muy útil para empezar a competir por oportunidades internacionales. C1 sería la evolución posterior, no una condición para empezar a buscar trabajo afuera.
